# Aurora-path

Aurora-path is a small Python project that generates smooth spiral-like coordinates and renders them as ASCII art.

## Features

- Generates a custom curved path with simple math.
- Prints coordinate data to the console.
- Renders the path as ASCII art.
- Easy to modify and extend.

## Files

- `main.py` : Main program.
- `README.md` : Project overview.

## Requirements

- Python 3.x

## How to Run

```bash
python main.py
